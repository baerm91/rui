# Aktives Projekt

In diesen Ordner kommt genau eine aus dem Editor exportierte JSON-Datei.
Der Dateiname ist beliebig; die Anwendung stellt sie automatisch als aktives
Projekt bereit.

Wenn mehrere `.json`-Dateien hier liegen, bricht der Start bzw. Build mit einer
eindeutigen Fehlermeldung ab. Zum Wechseln eines Projekts daher die bisherige
JSON entfernen und die neue Datei in diesen Ordner kopieren.
