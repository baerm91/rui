# RIU material assets

The bundled 1K PBR texture sets are used by the spatial exhibition editor and
loaded only when a surface selects the corresponding material.

- `beige_wall_002`: Poly Haven, Beige Wall 002, CC0
  https://polyhaven.com/a/beige_wall_002
- `marble_01`: Poly Haven, Marble 01, CC0
  https://polyhaven.com/a/marble_01
- `wood_floor`: Poly Haven, Wood Floor, CC0
  https://polyhaven.com/a/wood_floor
- `travertine_001`: ambientCG, Travertine 001, CC0
  https://ambientcg.com/view?id=Travertine001

Color maps use sRGB. Normal, roughness and AO maps remain in the default
non-color space. The source texture sets are redistributed under CC0.
